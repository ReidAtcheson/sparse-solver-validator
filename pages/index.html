Sparse Solver Validator

source code

Description

Sparse Solver Validator is a Rust toolkit for generating public sparse linear systems and validating a solver-owned solution. Problems are reproducible from a versioned generator. Validation can run locally, or a server can issue a signed, expiring challenge and return a signed certificate for a submitted proof.

This is development software and has not received an external security or numerical audit. The direct backend reveals the complete solution; the succinct backends do not claim zero knowledge. See the repository documentation for protocol details and limits.

Run a benchmark

The sparse-benchmark runner handles challenge acquisition, problem export, proof construction, submission, retries, and result-card creation. Download a complete benchmark configuration from the explorer below, then run: 

cargo build --release -p sparse-benchmark

target/release/sparse-benchmark start \
  --config benchmark.json \
  --runs-dir runs

# Solve the printed public/A.mtx and public/b.mtx system.
# Write the solution to the printed submission/x.json path.

target/release/sparse-benchmark resume runs/run-...

start creates an independent, resumable run directory and stops for your solver. resume safely advances that same run and writes result-card.json. If a network request is interrupted, run the same resume command again; the existing proof is reused.

See the runner guide for matrix-free export options, status inspection, card verification, and recovery semantics.
